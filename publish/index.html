apt.tracelabs.org

Signed Debian packages for the Trace Labs OSINT toolset. Built for Debian 13 (trixie), amd64.

# 1. Install the signing key

sudo apt install ca-certificates curl
sudo install -d -m 0755 /etc/apt/keyrings
sudo curl -fsSL -o /etc/apt/keyrings/tlosint-archive-keyring.gpg https://apt.tracelabs.org/tlosint-archive-keyring.gpg
gpg --show-keys /etc/apt/keyrings/tlosint-archive-keyring.gpg

The primary key fingerprint must be:

34CE 4BC7 4FC3 BFFE 7AD7  7C2A E7A5 76CA 1ABD 03CD

# 2. Add the repository

sudo tee /etc/apt/sources.list.d/tlosint.sources <<'EOF'
Types: deb
URIs: https://apt.tracelabs.org
Suites: stable
Components: main
Architectures: amd64
Signed-By: /etc/apt/keyrings/tlosint-archive-keyring.gpg
EOF
sudo apt update

# 3. Install packages

The whole toolset:

sudo apt install tlosint-meta

Or individual tools. To see what this repository provides:

apt list '?origin(^Trace Labs$)'
sudo apt install maigret
